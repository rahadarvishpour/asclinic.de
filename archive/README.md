# AURA // Aesthetic Lab — asclinic.de

Astro-Landingpage (deutsch). Warm Clinical Luxury, Graphit-Hero mit Partikel-Canvas, Sonne/Mond-Zyklus, scrollabhängige Hintergrund-Aufhellung, Haartransplantations-Slider (Vorher/Nachher), Behandlungs-Grid mit Video, Ergebnis-Slider, Buchungs-Footer.

## Lokal starten
```bash
npm install
npm run dev
```

## Ins Repository pushen (Inhalt ersetzen)
```bash
git clone https://github.com/rahadarvishpour/asclinic.de
cd asclinic.de
git rm -rf .
# Inhalt dieses Ordners hierher kopieren, dann:
git add -A
git commit -m "Neue Astro-Landingpage"
git push
```

Bilder: `public/assets/` (Vorher/Nachher-Fotos). Videos & Fotos: Mixkit / Unsplash (lizenzfrei).
